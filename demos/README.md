# Demos

This directory hosts runnable and reviewable demo timelines that complement product docs.

Use demos when you want concrete change-history slices, staged artifacts, and side-by-side evolution of governance states.

## Scope And Conventions

- `demos/` is treated as documentation space for navigation and indexing.
- Skill sample payloads under timeline folders are intentionally practical snapshots; they do not need to follow the full docs writing style contract.
- Index readmes in `demos/` and `demos/*/` should stay clean, navigable, and bilingual with root/counterpart links.

## How To Use This Folder

1. Start from a demo index page under `demos/*/README*.md`.
2. Open the timeline stage folder and read its local `Readme.md`.
3. Inspect skill assets under the nested sample skill folder (for example `SKILL.md`, `contract.json`, `assets/so-workflow/*`).
4. Cross-check runtime guidance against [docs/en/reference/products/so-guide.md](../docs/en/reference/products/so-guide.md) and [docs/en/reference/products/ao-guide.md](../docs/en/reference/products/ao-guide.md).
