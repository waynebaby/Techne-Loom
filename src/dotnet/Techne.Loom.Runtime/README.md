# Techne Loom Runtime

## English

RID-specific self-contained single-file runtime package for the unified Techne Loom CLI.

The package contains one executable under `tools/<rid>/loom[.exe]` and does not require a preinstalled .NET runtime. It exposes `loom agent`, `loom skill`, and the shared `loom ask` command. Run `loom --guide` for the package's current command and documentation contract.

## 中文

面向统一 Techne Loom CLI 的 RID 专属、自包含、单文件 runtime package。

本包在 `tools/<rid>/loom[.exe]` 提供唯一可执行文件，无需预装 .NET runtime。它提供 `loom agent`、`loom skill` 以及共享的 `loom ask` 命令。运行 `loom --guide` 查看此包对应的命令和文档契约。
